# Project agent entry point

Read `Meta.md` at the start of work in this repository. Follow its two-minute progress-update rule during active work. Load `PROJECT_CONTEXT.md`, `DOUGLAS_RECREATION_PLAN.md`, papers, and source code selectively for the current task; do not preload them all.

Treat `Log *.md` files as Git-versioned chronological records. Do not read or preload them at the start of a session; use `PROJECT_CONTEXT.md` and `DOUGLAS_RECREATION_PLAN.md` for current scope, status, and next steps. Add concise factual entries to the relevant dated log after material milestones. Read a specific log only when the user asks for its history or a past detail cannot be resolved from current context. Do not commit or push without explicit approval.
